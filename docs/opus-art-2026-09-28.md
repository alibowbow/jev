- 원본 게시물 39개: 38개 전체 영상과 1개 GIF 애니메이션.
- OpenVGLab 원작 SVG 11개: 서로 다른 캐릭터·장면이며 모든 SVG의 HTTP 응답과 XML 구조를 확인했다. 원문에 공개일 2026-09-24와 Opus 5.5 사용이 명시되어 있다.

- GIF와 SVG는 소리가 없는 애니메이션으로 표시한다. 새 원본 영상의 오디오를 직접 확인하지 않은 항목은 hasAudio=null로 둔다.
