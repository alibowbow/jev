## Gemini 4 Argon

- Google은 [2026-10-13 일반 공개](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-argon/)와 개발자용 모델 ID `gemini-4-argon`을 안내한다. 공식 [API 안내](https://ai.google.dev/gemini-api/docs/latest-model) 및 [모델 카드](https://deepmind.google/models/model-cards/gemini-4-argon/)를 확인했다. 입력과 출력은 1M 토큰 통합 한도를 공유하며, 장문 출력에는 API별 조건이 있다.
- 활용사례 **24개**: 제작자·커뮤니티의 작품·테스트·사용법 22개와 Google DeepMind Robotics 관련 공개 시연 2개. 하나는 CLI 사용 팁이고 두 개는 여러 모델의 비교 실험이다. 게시자 보고를 독립적인 성능 검증으로 취급하지 않는다. 일부 작업은 Blender, Cursor, Mixar, Lyria 또는 Nano Banana 등 다른 도구와 함께 진행됐다.
- 출발점은 [SandBase 목록](https://github.com/sandbase-lab/awesome-gemini4-argon)이었다. 각 X 게시물의 텍스트와 영상 ID·썸네일·게시일을 FxTwitter 공개 메타데이터로 대조하고, 게시물의 사용 모델·역할·한계를 개별 카드에 기록했다. 수상비행기와 깃발 게임은 [Google의 제작자 소개](https://blog.google/products-and-platforms/products/gemini/gemini-4-argon-builders/)에서도 확인했다. 로봇 시연은 [Google Developers 설명](https://developers.googleblog.com/en/gemini-4-argon-for-robotics/)을 함께 연결했다.
- 24개 원본 X MP4를 `ffprobe`로 확인해 **오디오 트랙 11개, 오디오 없는 영상 13개**를 기록했다. 스트림 존재와 실제 청취 품질·작품 기능의 검증은 다르다. 영상과 썸네일은 외부 호스트에서 읽고 복제하지 않는다. 주소나 접근 정책이 바뀔 수 있으므로 실패 시 원문을 제공한다.
- 원 게시물과 확인일, 각 영상·오디오 확인 결과는 [`argon-sources.json`](argon-sources.json)에 기록했다. 링크의 응답이나 제작자의 설명은 모델 실행 로그 전체를 확인했다는 뜻이 아니다.

## Gemini HTML 100

- [MiaAI-Lab의 원본 갤러리](https://miaai-lab.github.io/Gemini-4-Argon-HTML-Files/)는 100개 작품이 Gemini 4 Argon으로 생성됐다고 소개한다. 확인한 [저장소](https://github.com/MiaAI-Lab/Gemini-4-Argon-HTML-Files)의 커밋은 `d0ffae725103e0995f40ba80074bdf615a925470`이다.
- 001~100의 HTML, 같은 이름의 TXT, 썸네일 JPG를 각각 100개 확인했다. TXT의 프롬프트 본문과 갤러리 원문이 **100개 모두 일치**했다. [`argon-html100-sources.json`](argon-html100-sources.json)에 파일명과 SHA-256을 기록했다.
- 번호 001·025·050·075·100의 HTML·TXT·JPG 각 5개, 총 **15개 Pages 주소에 HEAD 요청을 보내 HTTP 200**을 확인했다. 나머지 Pages 링크의 응답과 100개 작품의 실제 실행·성능·정확성을 전수 검증한 것은 아니다.
- 원본 저장소는 공개 API에서 라이선스를 확인하지 못했고, 개별 작품 게시일도 알 수 없다. 코드 및 카드 상세의 TXT 출처는 확인 커밋에 고정했으며, 실행·썸네일·프롬프트는 제작자 Pages에 연결한다. 원본 파일은 이 저장소에 재배포하지 않는다.
