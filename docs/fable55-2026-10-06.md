# Fable 5.5 community-attributed use cases

Reviewed: 2026-10-06 UTC. Collection: `fable55.html` / `assets/fable55-data.js`.

## Attribution and selection

This is a collection of **creator-attributed demonstrations**, not confirmation of a released model. The [official Anthropic model overview](https://platform.claude.com/docs/en/models/overview) checked on the review date lists Fable 5.1 (`claude-fable-5-1`), Opus 5.5 and Sonnet 5.5. No Fable 5.5 model entry or announcement was found there or in the [official newsroom](https://www.anthropic.com/news). Private tests, routing behavior and actual backend model identity are not established by a creator's output or a model's self-description.

The page-level notice and short card labels preserve this distinction. Full evidence is in each card's detail dialog and the [machine-readable source ledger](fable55-sources.json).

20 projects by 16 creators were selected from 24 inspected original posts:

- 5 games
- 6 3D / simulation works
- 4 animation / art works
- 3 film / story works
- 2 product / brand works

The [community collection by coolbat](https://github.com/coolbat/awesome-fable-5.5-usecase) was used to discover creator links. Each selected original was separately checked through public X metadata for authorship, explicit model wording, posting time and native media. Korean copy was independently written from those original posts and sampled video frames. Duplicate source URLs and video IDs were checked against all eight earlier collections. No existing case was relabeled or copied to inflate the total.

Full tweets are not republished. The ledger retains a short model-attribution excerpt (at most 25 words per original post), source links and verification facts. Popularity metrics, unsupported quality rankings and model-release claims are omitted. Creator-reported timing, where mentioned, is explicitly attributed rather than presented as measured performance.

## Source examples and boundaries

- [Waymo / Lombard Street](https://x.com/mindblown_ai/status/2106112279079199037): creator names Fable 5.5 and Three.js and links a driving demo. The public page responds, but the cloud browser reports no usable WebGPU adapter, so driving was not functionally verified.
- [Clawd pixel platformer](https://x.com/blueemi99/status/2107108802440900621): the [creator artifact](https://claude.ai/artifact/Bor4eKVfaKakr6QSfoT8UZ) renders and starts its animated introduction in the cloud browser. This is a smoke check, not a full game playthrough.
- [Lower Manhattan by construction year](https://x.com/nroze22/status/2106183281293381661): the artifact loads its title and timeline, but this cloud browser cannot render the WebGL drawing. Building-data accuracy is not independently checked.
- [Three-body program](https://x.com/zAdrielsan/status/2105822678519001360): links the [initial code tree](https://github.com/AdrielSantana/three-bodies/tree/ccfc2a5a5e6d4dade7e100912d6c245f1a82a6d9). Later repository changes credit Opus 5.5, so they are not presented as Fable-generated. The proofs and claimed local frame rate were not reproduced.
- [Minecraft / Pokémon crossover](https://x.com/MozeTech/status/2106590326634983710): original video retained, but the disabled Vercel demo returned HTTP 402 and is not offered as a working demo.
- [Hugging Face fictional short](https://x.com/chetaslua/status/2105884276864782557): Blender and ElevenLabs roles are retained. It is a fictional animation, not evidence of the underlying event.

## Media and links

All 20 exact linked MP4 variants were downloaded and inspected with `ffprobe`: 15 contain audio streams and five do not. Sampled frames were reviewed; complete videos were not judged for quality or factual accuracy. Thumbnails and videos are linked from the original publisher hosts, not copied into this repository. Selecting a card loads the native video; third-party X widgets are never loaded.

Four demo pages responded with HTTP 200. HTTP success is not evidence of interactive correctness. Three GPU-dependent demos could not be started in this cloud browser. The Depths of Despair is present on its creator homepage; its Play link reaches the practice launcher, which reports missing WebGL 2. A fresh request to the deep play route returns HTTP 404, so its demo link deliberately stays on the original creator homepage. External availability can change after review.

## Integration and validation

- Adds a sixth model-navigation tab on all eleven static pages; retains the Fable 5.1 HTML 100 route and storage key.
- Reuses the existing renderer, source details, filters, sorting, bookmarking and video player. The shared change only adds the new collection and its concise attribution label.
- Keeps all eight earlier dataset files byte-identical.
- Adds regression tests for uniqueness, model labels, links, safe rendering, media filters, saved-state isolation, denied storage, source details, deep links, sharing, playback fallback, stale events and filter cleanup.
- Navigation adapts to six columns on tablet and three columns on narrow phones; no new framework, backend, API key or production build is introduced.

Run `npm ci`, `npm test`, `node --check` for every `assets/*.js`, and `git diff --check`. The final check results are recorded in the pull request.

Browser limits: the local Chromium process could not start because its sandboxed environment rejected a socket operation. The separate cloud browser rejected the localhost preview with `ERR_BLOCKED_BY_CLIENT`. Therefore actual rendering of the new JEV page at desktop/mobile widths is **not verified** before merge; DOM tests and CSS inspection do not substitute for that visual check. Public creator-demo observations above were performed separately in the cloud browser. No deployment or main-branch merge is part of this change.
