## Media and scope

No creator HTML, images or audio are copied into this repository. Cards link to original GitHub Pages execution URLs, matching `thumbs/*.jpg`, GitHub code and TXT prompts. Demos open in a new tab rather than loading 200 executable documents into the catalogue. Audio uses the originals’ explicit playback controls. Silent waveform and audio-console UI examples are described as visual studies where appropriate. Fictional weather, financial and scientific interfaces are identified as simulations or design concepts in the Korean summaries.
